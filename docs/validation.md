# 验证范围与 iPhone 验收

本次使用 Node.js 语法检查、纯逻辑和 Scriptable API Mock，没有真实 iPhone/Scriptable 连接。模拟通过不等于 iOS 验证完成。

## 自动化范围

运行 `node tools/check.mjs` 检查全部脚本语法和生成一致性，再执行逻辑、交互与远程入口测试。

当前共有 94 项测试（纯逻辑 19、运行与交互 38、背景 16、校准 8、远程入口 13），全部通过。日期相关逻辑此前另在北京时间、UTC 和纽约时区运行检查。背景测试覆盖旧配置/备份迁移、裁剪边界、15 种截图尺寸的全部布局与位置、原生自动裁剪、三尺寸保存、取消、写入失败、图片缺失/损坏、颜色与遮罩、离线读取和远程更新保留 PNG。

新增生日验证覆盖阳历每年循环、生日当天/次日、今年满岁、2 月 29 日、农历春节/中秋/腊月跨年/闰月回退/小月回退、1900—2100 年每月首末日与 ICU 中国历核对、原单事件脚本读取和编辑闰月字段，以及三种尺寸列表/面板排序与三条上限。分组回归覆盖生日与其他倒计时各自排序、各自最多三条、未来优先和过期保留，两组共十条数据在大号仅启用倒计时模块时展示六条。菜单精简回归覆盖记录直接展示和分页、末页删除后回退、单事件默认记录删除、编辑沿用历法、修改历法的保存/取消、当前紧凑配置的一页设置、非法设置取消不写入、预览尺寸复用、统一备份入口和恢复取消不覆盖；背景首页五项、高级操作取消不写入。新增流程回归覆盖单事件和多事件菜单直接提供添加事件/添加生日、三种生日历法选择、取消历法/表单不写入，以及日期错误重试保留所选历法。

覆盖日期/时区/跨日、今天和过期、待取筛选、车票排序/隐藏、倒计时共享、JSON 校验/冲突、1500 条记录、中文和 emoji 截断、小中大号布局预算、双行车票、中文管理/配置菜单、本地存储、损坏文件保留、有效快照、备份恢复和回滚、日历权限失败、快捷指令输入确认、远程发现/安装/缓存/异常响应/旧参数兼容。

Widget 模式不允许弹出任何 Mock 对话框，日历读取只在 App 内进行。布局测试验证代码预算和单行限制，不是像素或截图测试。

Mock 无法复现字体尺寸、Alert 滚动/键盘、iCloud 延迟、系统 URL 调起、权限弹窗和 iOS 刷新调度。

背景处理通过 Mock 验证 DrawContext 坐标、尺寸和遮罩调用。新增回归覆盖保存后读回、静默写入丢失不进入预览、同尺寸自动预览与 App 结束时保留该尺寸。未知分辨率的内置表不裁剪，本机校准按实际像素识别。校准测试覆盖三个尺寸、圆角和文字孔洞、全分辨率、无/多标记、参数转发、iOS 27 优先校准流程、保存及复用、错误不保存和旧备份迁移，以及拒绝空白截图确认时两个透明背景流程均不写入数据。没有 iPhone PNG 实际像素输出或桌面合成验证，尺寸表上游验证不等同于本项目真机验证。

另使用桌面 Chrome 执行实际校准桥接 JavaScript，解码一张虚构的 1206×2622 PNG，通过 Canvas 成功识别其预设矩形（81, 261, 1044, 1098），验证回调携带正确值。这是算法/浏览器验证，不是真实 iPhone 17/iOS 27 测量，也不证明这些数值是该设备的通用布局。校准时应以用户本机紫色组件截图为准。

`node tools/preview.mjs` 从 信息面板 的实际渲染树生成 `docs/dashboard-preview.html`。`dashboard-preview.png` 是该页面的浏览器截图，用于核对浅/深色和三种尺寸的设计；它使用演示数据、近似字体和图标，不是 iPhone 截图。

中文入口回归覆盖中文下载地址编码、清单、中文模块点击参数、全部旧英文参数兼容、离线旧缓存迁移和私人数据保留；中文路径穿越拒绝、损坏旧缓存拒绝迁移。

## iPhone 真机检查

1. 替换入口，联网运行，确认五个脚本进入列表；返回后原倒计时记录还在。
2. 添加三条快递（一个代码以零开头），检查三种尺寸、取件/恢复、长公司名和驿站备注。
3. 导入有效批量 JSON 和含无效记录的 JSON，确认后一种整批拒绝，原记录保留。
4. 添加多张车票，检查日期、时区、路线、车次、时间和席别；测试到达时间与隐藏设置。
5. 原 `倒计时` 与新列表交替管理同一个事件，确认共用数据库、默认事件和旧参数可用。
6. 配置默认/紧凑面板的模块、顺序、条数、空数据隐藏和主题，切换系统深浅色。
7. 用超长中文、最小屏幕和显示缩放检查小/中/大号。大号多个卡片，中号并列，小号一个模块。
8. 在桌面和负一屏添加组件，测试卡片跳转、整体点击，以及入口和直接脚本两种模式。
9. 用 README URL 示例、快捷指令 JSON 输入调起 `快递`；确认接收、取消不保存、确认保存。该链路目前仅有 API 依据及 Mock 验证。
10. 启用日历并授权，刷新缓存；拒绝权限时其他模块仍显示，Widget 不弹权限。选日历添加车票并检查起止时间。
11. 导出备份，修改记录后恢复，检查还原。无效备份不覆盖数据。
12. 飞行模式执行直接脚本和入口，验证有效缓存展示；首次无缓存应明确报错。
13. 保留备份后测试损坏 JSON（建议用开发数据），检查错误提示、快照恢复和其他模块隔离。
14. 选相册图片，检查三个尺寸的居中裁剪、文字颜色及 0/25/80% 遮罩；拒绝照片权限、取消选图应保留原背景。
15. 用实际桌面完整截图制作三个尺寸的透明背景，检查位置、图标大小或 mini 型号选项、自动裁剪后的同尺寸预览、取消不保存。对齐桌面实际组件，并在换位置后重新制作。检查未知分辨率报错及“预览当前背景”提示。
16. 飞行模式检查背景展示无弹窗；运行远程更新后检查图片与数据仍在。删除某张背景开发测试图后确认主题回退和提示，JSON 换设备恢复后重新选图。

17. 在新系统用 `calibrate` / `信息面板|calibrate` 临时显示紫色校准组件，检查两张完整截图的原生选图、自动识别、错误拒绝、保存后预览、恢复普通参数、桌面边缘对齐及复用位置。改变缩放/图标大小后重新校准，确认校准图不会混入最终背景。

18. 打开「倒计时」确认首页有「添加事件」「添加生日」，通过添加生日分别选择阳历、农历、闰月农历并填写出生年月日，检查年龄和下次日期；添加至少五个生日，确认列表和面板分为生日与其他两组，各自按日期排序且最多三条，并检查单事件组件及旧普通倒计时仍能读取。

修改记录后先用 App 预览验证保存结果，再等待系统刷新；不能以桌面是否立即变化判断保存失败。

## 用户提供截图的测量范围

用户两张附件均为 588×1280，组件图与空白图的壁纸区域经像素对比无位移。用黑色组件与空白壁纸的差异确定大号顶部可见边界，取矩形（38,132,512,534），原图两个轴分别换算并对边界取整。入口限定 588×1280 与 1206×2622，其他尺寸拒绝。测试覆盖两种分辨率换算、无校准选图保存、错误尺寸拒绝及私人记录保留。图片未加入仓库。

压缩截图边缘存在抗锯齿和重采样，当前测量不是系统原生几何 API 结果；最终接缝仍需用户桌面复验。不把该用户当前布局推广为全部 iPhone 17/iOS 27 的固定尺寸。
